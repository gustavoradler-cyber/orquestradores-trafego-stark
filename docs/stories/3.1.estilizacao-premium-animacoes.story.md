# Story 3.1: Estilização Premium e Micro-animações

## Status

Draft

## Story

**As a** usuário,  
**I want** ver uma interface com design sofisticado (glassmorphism, gradientes, animações suaves) ao interagir com a calculadora,  
**so that** a experiência de uso seja visualmente diferenciada e agradável.

## Acceptance Criteria

1. O fundo da página usa gradiente azul-violeta escuro (`#0f0f1a` → `#1a1a2e` ou equivalente)
2. Os cards (calculadora e histórico) aplicam glassmorphism: `backdrop-filter: blur()` + `background: rgba(255,255,255,0.05)` com borda sutil translúcida
3. Botões numéricos e de operação têm `border-radius: 12px`, sombra suave e estado hover com elevação (`transform: translateY(-2px)`) ou efeito de brilho
4. Clicar em qualquer botão dispara micro-animação de press (ex: `transform: scale(0.95)` + transição 100ms)
5. Novos itens adicionados ao histórico entram com transição suave (fade-in ou slide)
6. A tipografia usa Inter ou Outfit (Google Fonts) — peso light/regular no display superior, bold no resultado
7. O contraste texto/fundo atende WCAG AA (mínimo 4.5:1 para texto normal)

```css
  --card-radius: 20px;
  --btn-radius: 12px;

  --transition-normal: 300ms ease;

```

### Glassmorphism — Nota de Compatibilidade

`backdrop-filter` funciona em Chrome, Firefox 103+, Safari (com prefixo `-webkit-`). Para browsers antigos sem suporte, o card aparece com background sólido semi-transparente — aceitável como fallback.

```css
.calculator, .history-panel {
  background: var(--bg-card);
  backdrop-filter: blur(var(--card-blur));
  -webkit-backdrop-filter: blur(var(--card-blur));
  border: 1px solid var(--border-color);
  border-radius: var(--card-radius);
}
```

### Animação Fade-in do Histórico

```css
@keyframes fadeSlideIn {
  from {
    opacity: 0;
    transform: translateY(-10px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.history-item {
  animation: fadeSlideIn 300ms ease;
}
```

### Contraste WCAG AA

Branco (#ffffff) sobre rgba(255,255,255,0.05) que fica sobre #1a1a2e resulta em fundo efetivo ~#1f1f34. Contraste branco/#1f1f34 ≈ 12:1 — passa WCAG AA e AAA. Se usar `text-secondary` (60% opacidade branco), verificar com DevTools.
