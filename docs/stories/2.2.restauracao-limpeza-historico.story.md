# Story 2.2: Restauração e Limpeza do Histórico

Draft

## Story

**As a** usuário,  
**I want** clicar em um item do histórico para restaurá-lo no display e limpar o histórico com um botão,  
**so that** eu possa retomar cálculos anteriores e manter o painel organizado.

## Acceptance Criteria

1. Clicar em um item do histórico popula o display superior com a expressão e o display inferior com o resultado daquela operação
2. Após restaurar um item, o usuário pode continuar a partir do resultado (pressionando um operador)
3. O botão "Limpar histórico" remove todas as entradas da lista e exibe o placeholder novamente
4. O botão "Limpar histórico" não afeta o estado atual do display (cálculo em andamento não é perdido)
5. O histórico existe apenas em memória da sessão — ao recarregar a página, o histórico começa vazio

### Event Delegation (Padrão Necessário)

A lista `#history-list` é populada dinamicamente. Usar event delegation:

```javascript
document.getElementById('history-list').addEventListener('click', (e) => {
  const item = e.target.closest('.history-item');
  if (!item) return; // clique no placeholder ou área vazia
  const id = Number(item.dataset.id);
  const historyEntry = historyItems.find(h => h.id === id);
  if (historyEntry) restoreFromHistory(historyEntry);
});
```

### Restauração do Estado Interno

```javascript
function restoreFromHistory(item) {
  // Atualiza displays
  document.getElementById('expression-display').textContent = item.expression;
  document.getElementById('result-display').textContent = item.result;
  
  // Atualiza estado para permitir continuar a partir do resultado
  state.previousInput = String(item.result);
  state.currentInput = '';
  state.operator = null;
  state.hasResult = true;
  state.hasError = false;
}
```

### Limpeza de Histórico — Isolamento

```javascript
function clearHistory() {
  historyItems.length = 0; // limpa array sem reatribuir (preserva referência)
  renderHistory();          // exibe placeholder
  // NÃO tocar no state da calculadora
}
```

### AC 5 — Sem Persistência

O histórico vive apenas no array `historyItems` em memória. **Não usar `localStorage`** para o histórico (apenas para tema). Ao recarregar, o array é reinicializado vazio.
