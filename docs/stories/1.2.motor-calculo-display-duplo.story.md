# Story 1.2: Motor de Cálculo e Display Duplo

Draft

## Story

**As a** usuário,  
**I want** realizar cálculos com as 4 operações básicas e ver a expressão construída no display superior e o resultado no display inferior,  
**so that** eu tenha contexto visual completo durante e após cada operação.

## Acceptance Criteria

1. Clicar em dígitos atualiza o display inferior com o número sendo inserido
2. Clicar em um operador (+, -, ×, ÷) move o número atual para o display superior como início da expressão (ex: `12 ×`) e limpa o display inferior para novo input
3. Clicar em `=` completa a expressão no display superior (ex: `12 × 4 =`), calcula o resultado e exibe no display inferior
4. A soma, subtração, multiplicação e divisão retornam resultados numericamente corretos (testado com pelo menos 3 operações por tipo)
5. Divisão por zero exibe `Erro: Divisão por zero` no display inferior e `÷ 0 =` no superior; o botão C retorna ao estado limpo
6. O botão C (Clear) limpa ambos os displays e reinicia o estado interno
7. O botão ⌫ (Backspace) remove o último dígito do input atual no display inferior
8. O ponto decimal (`.`) pode ser inserido uma única vez por número; cliques adicionais são ignorados
9. O estado interno da calculadora é gerenciado por funções puras e separadas da manipulação do DOM

## Dev Notes

### Prerequisito

Story 1.1 deve estar completa. Este script conecta nos elementos HTML criados na 1.1:
- `#expression-display` — exibe expressão em construção
- `#result-display` — exibe resultado ou input atual
- Botões com `data-type` e `data-value` (definidos na 1.1)

### Padrão de Seleção de Botões

```javascript
// Usar data-attributes para selecionar tipos de botão
document.querySelectorAll('[data-type="digit"]').forEach(btn => {
  btn.addEventListener('click', () => handleDigit(btn.dataset.value));
});
document.querySelectorAll('[data-type="operator"]').forEach(btn => {
  btn.addEventListener('click', () => handleOperator(btn.dataset.value));
});
```

### Estrutura de Estado Recomendada

```javascript
let state = {
  currentInput: '',
  previousInput: '',
  operator: null,
  expression: '',
  hasResult: false,
  hasError: false
};

function resetState() {
  state = { currentInput: '', previousInput: '', operator: null, expression: '', hasResult: false, hasError: false };
}
```

### Função `calculate` — Assinatura Esperada

```javascript
function calculate(a, op, b) {
  const numA = parseFloat(a);
  const numB = parseFloat(b);
  switch(op) {
    case '+': return numA + numB;
    case '-': return numA - numB;
    case '×': return numA * numB;
    case '÷':
      if (numB === 0) return { error: 'Divisão por zero' };
      return numA / numB;
  }
}
```

### Regra Anti-eval

**NUNCA usar `eval()` ou `Function()` para calcular expressões.** A função `calculate()` deve usar lógica explícita com switch/if.
