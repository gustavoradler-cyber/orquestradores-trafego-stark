# Story 2.1: Registro e Exibição do Histórico

## Story

**As a** usuário,  
**I want** que cada operação que eu concluir (pressionando =) seja automaticamente registrada no painel de histórico,  
**so that** eu possa revisar o que calculei sem precisar redigitar.

## Acceptance Criteria

1. Ao pressionar `=`, a operação concluída (expressão + resultado, ex: `12 × 4 = 48`) é adicionada ao topo da lista de histórico
2. O histórico exibe no mínimo as últimas 10 operações na sessão
3. O item mais recente aparece no topo da lista
4. Enquanto não há operações, o painel exibe placeholder (`Nenhuma operação ainda`)
5. Operações com erro (divisão por zero) NÃO são registradas no histórico
6. A lista de histórico tem scroll próprio se o número de itens ultrapassar a altura do painel

### Onde Integrar

```javascript
// Em handleEquals() — adicionar após cálculo bem-sucedido:
function handleEquals() {
  const result = calculate(state.previousInput, state.operator, state.currentInput);
  if (result && result.error) {
    // exibir erro, NÃO adicionar ao histórico
    state.hasError = true;
    updateDisplays(`Erro: ${result.error}`, ...);
    return;
  }
  const fullExpression = `${state.previousInput} ${state.operator} ${state.currentInput} =`;
  updateDisplays(fullExpression, result);
  addToHistory(fullExpression, result);  // ← integração desta story
}
```

### Estrutura de um Item do Histórico

```javascript
{
  id: Date.now(),          // identificador único para chave DOM
  expression: '12 × 4 =', // expressão completa com =
  result: 48,              // valor numérico do resultado
  timestamp: new Date().toISOString()
}
```

### Renderização do Histórico

```javascript
function renderHistory() {
  const list = document.getElementById('history-list');
  if (historyItems.length === 0) {
    list.innerHTML = '<li class="history-empty">Nenhuma operação ainda</li>';
    return;
  }
  list.innerHTML = historyItems.map(item => `
    <li class="history-item" data-id="${item.id}">
      <span class="history-expression">${item.expression}</span>
      <span class="history-result">${item.result}</span>
    </li>
  `).join('');
}
```
