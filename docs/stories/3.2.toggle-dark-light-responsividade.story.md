# Story 3.2: Toggle Dark/Light e Responsividade

## Status

Draft

## Executor Assignment

- **Executor:** @dev
- **Quality Gate:** @qa
- **Quality Gate Tools:** checklist-runner, browser
- **Prerequisito:** Story 3.1 deve estar Done

## Story

**As a** usuário,  
**I want** alternar entre modo escuro e claro com um botão, e usar a calculadora no celular,  
**so that** eu possa adaptar a interface ao meu ambiente e dispositivo.

## Acceptance Criteria

1. Um botão/ícone de toggle de tema está visível no header ou canto superior da calculadora
2. Clicar no toggle alterna imediatamente entre dark mode e light mode via troca de classe no elemento `<html>` (ex: `class="light"`)
3. Light mode aplica: fundo cinza-claro (`#f0f2f5`), cards brancos com sombra, acentos em azul-violeta (`#6c63ff`), texto escuro
4. A preferência de tema é salva em `localStorage` (chave `calculadora-tema`) e aplicada ao carregar a página antes de qualquer render visível (sem flash de tema errado)
5. Em viewport de 375px de largura, o layout muda para coluna única: calculadora em cima, histórico embaixo
6. Em mobile, todos os botões do teclado são acessíveis e clicáveis sem zoom (tamanho mínimo 44×44px por botão)
7. O painel de histórico em mobile tem altura máxima definida com scroll próprio

## Dev Notes

### Prerequisito

Story 3.1 deve estar completa. Esta story adiciona:
- Script inline no `<head>` do HTML existente (anti-flash)
- Botão de toggle no HTML existente
- Tokens `.light` no CSS existente (definidos na 1.1 mas agora completados)
- Event listener no `script.js` existente

### Anti-Flash — Crítico

O script de tema DEVE estar no `<head>`, antes do `<link rel="stylesheet">`. Se colocado no final do `<body>` ou no `script.js` (diferido), o usuário verá um flash do tema padrão antes do tema salvo ser aplicado.

```html
<head>
  <!-- 1. Script inline anti-flash — ANTES do CSS -->
  <script>
    (function() {
      const saved = localStorage.getItem('calculadora-tema');
      if (saved === 'light') document.documentElement.classList.add('light');
    })();
  </script>
  <!-- 2. CSS -->
  <link rel="stylesheet" href="style.css">
  <!-- 3. Fonte -->
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;700&display=swap" rel="stylesheet">
</head>
```

### Ícone do Toggle

Usar caracteres Unicode ou emoji:
- Dark mode ativo (próximo: ir para light) → mostrar `☀️` ou `○` (sol)
- Light mode ativo (próximo: ir para dark) → mostrar `🌙` ou `●` (lua)

Alternativa: SVG inline simples.

### Light Mode — Fundo sem Gradiente Escuro

No `.light`, o `body` deve sobrescrever o gradiente:
```css
.light body {
  background: var(--bg-primary); /* #f0f2f5 */
}
/* ou */
.light {
  --gradient-bg: #f0f2f5;
}
body {
  background: var(--gradient-bg, linear-gradient(135deg, #0f0f1a, #1a1a2e));
}
```

### Responsividade — Breakpoint

Usar `640px` como breakpoint (calculadora fica estreita antes disso em layouts lado a lado).
